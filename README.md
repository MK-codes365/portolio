## 📦 Getting Started

### Prerequisites
- Node.js `>= 19.9.0`
- npm `>= 9.6.3`

### Installation

```bash
# Clone the repository
git clone https://github.com/MK-codes365/portolio.git

# Navigate to project directory
cd portolio

# Install dependencies (this also sets up the Draco decoder)
npm install
```

### Local Development

```bash
# Start local development server on http://localhost:7777
npm run dev
```

### Storybook UI Component Explorer

```bash
npm run dev:storybook
```

### Production Build

```bash
npm run build
```

## 🚀 Deployment

### Deploy on Vercel (Recommended)
1. Import this repository into [Vercel](https://vercel.com).
2. Framework Preset will automatically detect **Remix**.
3. Hit **Deploy**.
